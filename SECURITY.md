# Security Policy

This repository primarily contains research code, proofs, and reproducibility artifacts. Please do not publicly disclose a vulnerability that could enable code execution, dependency compromise, artifact substitution, forged certificates, or CI/release tampering.

Report security-sensitive problems privately to the repository owner through GitHub's private vulnerability reporting feature when available, or through the public contact information on the maintainer's GitHub profile.

Ordinary mathematical errors, proof gaps, incorrect outputs, and reproducibility failures are not security vulnerabilities. Report those with the mathematical-error or computational-discrepancy issue template.

Include affected paths, reproduction steps, impact, and any proposed mitigation. No response-time guarantee is currently offered because this is an independently maintained research project.

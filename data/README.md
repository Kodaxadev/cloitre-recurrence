# Data and certificate formats

Every tracked artifact in `data/` and `certificates/` is plain text. There are no
binary files in this repository, and nothing here needs the Rust parser to read.
All CSVs carry a header row; `.gitattributes` pins them to LF so their SHA256
hashes are byte-stable on every platform.

Throughout, the orbit is $b_1=m$, $b_{n+1}=b_n+(b_n\bmod n)$; $t$ is the
stabilization index and $c$ the eventual increment.

## CSV files

| File | Columns | Meaning |
|---|---|---|
| `data/scan_1M.csv` | `m,t,c,b_t` | Per-start outcome for every $m\le10^6$: stabilization index, eventual increment, and the value at stabilization. |
| `data/census_10M.csv` | `t,c,witness_m,b_t` | One row per *distinct orbit* found in $m\le10^7$, keyed by its $(t,c)$; `witness_m` is the smallest start reaching it. This is the compressed form behind K7's 9,911 orbits. |
| `data/records_top10.csv` | `m,t,c,b_t` | The ten largest stabilization indices in $m\le10^7$, K2's record first. |
| `data/epochs_m11489.csv` | `m,n_end,steps,mean_kappa,mean_rho,p_down,p_flat,p_up` | Epoch statistics for one orbit: the measured $\Delta q$ frequencies behind heuristic H3, plus mean normalized quotient and remainder. |
| `certificates/spectrum_m259.csv` | `m,t,c,b_t` | The complete finite range supplied by Theorem 18 for the minimal nonsurjectivity certificate (C20). Regenerated by `independent/verify_small_spectrum.py`. |

## Checkpoint files

`data/*.ckpt` is a single comma-separated line:

```text
hi,digest,record_t,record_m
```

`hi` is the last start index swept, `digest` a `0x`-prefixed FNV-1a hash of the
sweep trajectory used to detect divergence between implementations, and
`record_t` / `record_m` the best stabilization index seen and the start attaining
it. Example, `data/scan_1M.ckpt`:

```text
1000000,0x888496cf7dd808f5,9363863,31873
```

## Text certificates

`certificates/safe_n1000000.txt` is a `key: value` report, one pair per line,
for the K13 safe-map checkpoint at $N=10^6$. Its keys record the start index, the
number of positive initial states, the step at which the compressed safe set
empties, and the trajectory digest. Regenerated by
`independent/verify_safe_certificate.py`, and hash-checked in CI.

`data/excluded_increments.txt` is a commented list of increments that are never
an eventual increment, with the Theorem 18 bound quoted in the header. Lines
beginning with `#` are commentary; the rest are one integer per line.

## Logs

`data/*.log` are human-readable run transcripts kept for provenance: the command
line, the covering identity `merges + absorbed + live == starts`, and timings.
They are not consumed by any tool.

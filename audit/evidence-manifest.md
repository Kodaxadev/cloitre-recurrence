## Logical certificate digests

The denominator-family certificate is a SHA-256 digest over the exact symbolic
family records generated by `scripts/periodic_phase_blocks.py`, not a file hash.

```text
command:
python scripts/periodic_phase_blocks.py --max-denominator 501

odd denominators checked:             250
denominators with no boundary family:  81
boundary families checked:            463
phase-integral survivors:                0
certificate SHA-256:
1508d04cc91c8a007d17028efb24fe726785f4f210272721d8fc7f6149d4bb06
```

The script asserts this digest for the stated bound. This finite certificate is
supporting evidence for K11; Theorem 38 claims a separate symbolic all-period
argument and must be audited independently of this computation.

The small-spectrum certificate is independently regenerated and checked by:

```text
python independent/verify_small_spectrum.py
```

It covers every start in the complete Theorem 18 ranges needed to exclude
increments 5 and 7 and gives explicit witnesses for 1, 2, 3, 4, and 6.
